🔐 How Indian Credentials are Cryptographically Secured:

1. Public SHA-256 Hash

Every card has a unique, irreversible 256-bit cryptographic fingerprint anchored directly to the ledger.

2. RSA Digital Signature

Signed using the Government Authority's private key (GOV-NATIONAL-KEY-2026) and validated using the public key.

3. Zero-Tamper Proof

Altering a single digit in the card number or name causes instant hash mismatch and cryptographic rejection.
